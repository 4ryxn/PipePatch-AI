# Phase 6 repair-guidance sources

PipePatch keeps its wording generic and non-branded. These manufacturer pages informed the high-level safety principles only; the selected product label and local requirements always take priority.

- [Oatey: How to Solvent Weld Plastic Pipe](https://www.oatey.com/resources/project-guides/solvent-welding) — cut/deburr, dry-fit, prime where required, cement, and allow cure before testing.
- [Charlotte Pipe: Solvent welding guidance](https://www.charlottepipe.com/articles/solvent-welding-how-to-join-plastic-pipe-and-fittings-like-a-pro) — compatible materials, primer/cement preparation, and product-specific curing guidance.
- [Rain Bird: Sprinkler System Installation Guide](https://www.rainbird.com/homeowners/sprinkler-system-installation-guide) — irrigation PVC context and applying cement to pipe/fitting surfaces.

Solvent cement chemically welds compatible plastic surfaces. Follow the specific primer/cement and fitting instructions for set and cure time; PipePatch deliberately does not state a universal cure time.
